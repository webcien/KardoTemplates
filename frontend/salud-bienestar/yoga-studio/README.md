# Yoga Studio - Plantilla para KardoCore

Plantilla zen y minimalista para estudios de yoga, meditación y bienestar holístico

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install yoga-studio
```

## Paleta de Colores

- Primary: `#8B5CF6`
- Secondary: `#A78BFA`
- Accent: `#EC4899`
