# Mental Health Center - Plantilla para KardoCore

Plantilla cálida y acogedora para centros de salud mental, psicólogos y terapeutas

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install mental-health-center
```

## Paleta de Colores

- Primary: `#10B981`
- Secondary: `#34D399`
- Accent: `#6366F1`

## Tags

psicología, terapia, salud mental, bienestar emocional
