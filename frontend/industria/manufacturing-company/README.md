# Manufacturing Company - Plantilla para KardoCore

Plantilla robusta para empresas manufactureras e industriales

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install manufacturing-company
```

## Paleta de Colores

- Primary: `#1E3A8A`
- Secondary: `#3B82F6`
- Accent: `#F59E0B`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
