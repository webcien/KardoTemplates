# Construction Company - Plantilla para KardoCore

Plantilla sólida para empresas de construcción y contratistas

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install construction-company
```

## Paleta de Colores

- Primary: `#D97706`
- Secondary: `#F59E0B`
- Accent: `#1E40AF`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
