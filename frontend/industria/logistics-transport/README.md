# Logistics & Transport - Plantilla para KardoCore

Plantilla eficiente para empresas de logística y transporte

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install logistics-transport
```

## Paleta de Colores

- Primary: `#0EA5E9`
- Secondary: `#06B6D4`
- Accent: `#10B981`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
