# Creative Portfolio - Plantilla para KardoCore

Plantilla artística para diseñadores, artistas y creativos

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install creative-portfolio
```

## Paleta de Colores

- Primary: `#8B5CF6`
- Secondary: `#A78BFA`
- Accent: `#EC4899`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
