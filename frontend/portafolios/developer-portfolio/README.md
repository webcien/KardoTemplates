# Developer Portfolio - Plantilla para KardoCore

Plantilla técnica para desarrolladores y programadores

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install developer-portfolio
```

## Paleta de Colores

- Primary: `#10B981`
- Secondary: `#34D399`
- Accent: `#3B82F6`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
