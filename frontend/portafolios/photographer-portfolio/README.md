# Photographer Portfolio - Plantilla para KardoCore

Plantilla visual para fotógrafos profesionales

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install photographer-portfolio
```

## Paleta de Colores

- Primary: `#0F172A`
- Secondary: `#1E293B`
- Accent: `#F59E0B`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
