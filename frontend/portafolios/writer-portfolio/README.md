# Writer Portfolio - Plantilla para KardoCore

Plantilla elegante para escritores y redactores

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install writer-portfolio
```

## Paleta de Colores

- Primary: `#7C2D12`
- Secondary: `#92400E`
- Accent: `#DC2626`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
