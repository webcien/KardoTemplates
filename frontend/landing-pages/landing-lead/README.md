# Lead Generation Landing - Plantilla para KardoCore

Plantilla optimizada para captura de leads y conversión

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install landing-lead
```

## Paleta de Colores

- Primary: `#10B981`
- Secondary: `#34D399`
- Accent: `#3B82F6`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
