# App Landing Page - Plantilla para KardoCore

Plantilla impactante para lanzamiento de aplicaciones móviles

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install landing-app
```

## Paleta de Colores

- Primary: `#8B5CF6`
- Secondary: `#A78BFA`
- Accent: `#F59E0B`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
