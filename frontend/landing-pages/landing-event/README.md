# Event Landing Page - Plantilla para KardoCore

Plantilla llamativa para promoción de eventos

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install landing-event
```

## Paleta de Colores

- Primary: `#DC2626`
- Secondary: `#EF4444`
- Accent: `#F59E0B`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
