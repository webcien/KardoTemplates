# SaaS Product - Plantilla para KardoCore

Plantilla moderna para productos SaaS y software como servicio

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install saas-product
```

## Paleta de Colores

- Primary: `#3B82F6`
- Secondary: `#60A5FA`
- Accent: `#10B981`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
