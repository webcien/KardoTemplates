# SaaS CRM - Plantilla para KardoCore

Plantilla empresarial para sistemas CRM y gestión de clientes

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install saas-crm
```

## Paleta de Colores

- Primary: `#1E40AF`
- Secondary: `#3B82F6`
- Accent: `#10B981`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
