# Conference Center - Plantilla para KardoCore

Plantilla profesional para centros de conferencias y espacios para eventos

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install conference-center
```

## Paleta de Colores

- Primary: `#1E40AF`
- Secondary: `#3B82F6`
- Accent: `#10B981`
