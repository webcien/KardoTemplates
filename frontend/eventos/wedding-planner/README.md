# Wedding Planner - Plantilla para KardoCore

Plantilla romántica y elegante para organizadores de bodas

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install wedding-planner
```

## Paleta de Colores

- Primary: `#DB2777`
- Secondary: `#EC4899`
- Accent: `#F472B6`
