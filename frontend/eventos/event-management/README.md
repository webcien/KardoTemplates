# Event Management - Plantilla para KardoCore

Plantilla versátil para empresas de organización de eventos corporativos

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install event-management
```

## Paleta de Colores

- Primary: `#7C3AED`
- Secondary: `#8B5CF6`
- Accent: `#F59E0B`
