# Property Listings - Plantilla para KardoCore

Plantilla optimizada para listados de propiedades y búsqueda inmobiliaria

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install property-listings
```

## Paleta de Colores

- Primary: `#0F766E`
- Secondary: `#14B8A6`
- Accent: `#F59E0B`
