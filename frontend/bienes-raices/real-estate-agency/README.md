# Real Estate Agency - Plantilla para KardoCore

Plantilla profesional para agencias inmobiliarias y corredores de propiedades

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install real-estate-agency
```

## Paleta de Colores

- Primary: `#1E40AF`
- Secondary: `#3B82F6`
- Accent: `#10B981`

## Tags

inmobiliaria, propiedades, bienes raíces, casas, venta
