# Bookstore - Plantilla para KardoCore

Plantilla clásica y acogedora para librerías y tiendas de libros

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install bookstore
```

## Paleta de Colores

- Primary: `#7C2D12`
- Secondary: `#92400E`
- Accent: `#DC2626`
