# Electronics Shop - Plantilla para KardoCore

Plantilla tecnológica para tiendas de electrónica y gadgets

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install electronics-shop
```

## Paleta de Colores

- Primary: `#0EA5E9`
- Secondary: `#06B6D4`
- Accent: `#F59E0B`
