# Fashion Store - Plantilla para KardoCore

Plantilla moderna y elegante para tiendas de moda y ropa online

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install ecommerce-fashion
```

## Paleta de Colores

- Primary: `#EC4899`
- Secondary: `#F472B6`
- Accent: `#8B5CF6`
