# Handmade Crafts - Plantilla para KardoCore

Plantilla artesanal y cálida para productos hechos a mano

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install handmade-crafts
```

## Paleta de Colores

- Primary: `#D97706`
- Secondary: `#F59E0B`
- Accent: `#10B981`
