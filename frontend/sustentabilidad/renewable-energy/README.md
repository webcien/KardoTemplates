# Renewable Energy - Plantilla para KardoCore

Plantilla innovadora para empresas de energía renovable

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install renewable-energy
```

## Paleta de Colores

- Primary: `#0EA5E9`
- Secondary: `#06B6D4`
- Accent: `#10B981`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
