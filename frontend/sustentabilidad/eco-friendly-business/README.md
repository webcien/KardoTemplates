# Eco-Friendly Business - Plantilla para KardoCore

Plantilla verde para negocios ecológicos y sustentables

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install eco-friendly-business
```

## Paleta de Colores

- Primary: `#059669`
- Secondary: `#10B981`
- Accent: `#F59E0B`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
