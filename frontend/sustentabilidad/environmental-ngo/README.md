# Environmental NGO - Plantilla para KardoCore

Plantilla comprometida para ONGs ambientales

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install environmental-ngo
```

## Paleta de Colores

- Primary: `#047857`
- Secondary: `#059669`
- Accent: `#F59E0B`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
