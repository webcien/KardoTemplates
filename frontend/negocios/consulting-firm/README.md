# Consulting Firm - Plantilla para KardoCore

Plantilla sofisticada para firmas de consultoría, asesores y servicios profesionales

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install consulting-firm
```

## Paleta de Colores

- Primary: `#0F172A`
- Secondary: `#334155`
- Accent: `#3B82F6`
