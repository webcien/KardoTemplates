# Corporate Business - Plantilla para KardoCore

Plantilla profesional y elegante para empresas corporativas y negocios establecidos

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install corporate-business
```

## Paleta de Colores

- Primary: `#1E40AF`
- Secondary: `#3B82F6`
- Accent: `#10B981`
