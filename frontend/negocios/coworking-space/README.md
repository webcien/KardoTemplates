# Coworking Space - Plantilla para KardoCore

Plantilla vibrante para espacios de coworking, oficinas compartidas y comunidades de trabajo

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install coworking-space
```

## Paleta de Colores

- Primary: `#06B6D4`
- Secondary: `#22D3EE`
- Accent: `#F59E0B`
