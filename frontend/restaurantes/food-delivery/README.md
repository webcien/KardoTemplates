# Food Delivery - Plantilla para KardoCore

Plantilla dinámica para servicios de entrega de comida y delivery

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install food-delivery
```

## Paleta de Colores

- Primary: `#DC2626`
- Secondary: `#EF4444`
- Accent: `#F59E0B`
