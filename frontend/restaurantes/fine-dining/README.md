# Fine Dining - Plantilla para KardoCore

Plantilla sofisticada para restaurantes de alta cocina y gastronomía

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install fine-dining
```

## Paleta de Colores

- Primary: `#0F172A`
- Secondary: `#1E293B`
- Accent: `#D4AF37`
