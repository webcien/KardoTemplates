# Café & Bistro - Plantilla para KardoCore

Plantilla acogedora para cafeterías, bistros y coffee shops

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install cafe-bistro
```

## Paleta de Colores

- Primary: `#78350F`
- Secondary: `#92400E`
- Accent: `#F59E0B`
