# Freelance Consultant - Plantilla para KardoCore

Plantilla ejecutiva para consultores independientes

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install freelance-consultant
```

## Paleta de Colores

- Primary: `#1E40AF`
- Secondary: `#3B82F6`
- Accent: `#F59E0B`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
