# Law Firm - Plantilla para KardoCore

Plantilla profesional y confiable para bufetes de abogados y servicios legales

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install law-firm
```

## Paleta de Colores

- Primary: `#0F172A`
- Secondary: `#1E293B`
- Accent: `#B8860B`

## Tags

abogados, legal, derecho, bufete, jurídico
