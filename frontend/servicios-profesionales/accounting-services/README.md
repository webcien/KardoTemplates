# Accounting Services - Plantilla para KardoCore

Plantilla clara y organizada para contadores, auditores y servicios financieros

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install accounting-services
```

- Primary: `#1E40AF`
- Secondary: `#3B82F6`
- Accent: `#059669`
