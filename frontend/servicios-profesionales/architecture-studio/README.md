# Architecture Studio - Plantilla para KardoCore

Plantilla elegante y visual para estudios de arquitectura y diseño

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install architecture-studio
```

## Paleta de Colores

- Primary: `#374151`
- Secondary: `#6B7280`
- Accent: `#F59E0B`
