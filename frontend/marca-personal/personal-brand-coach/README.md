# Personal Brand Coach - Plantilla para KardoCore

Plantilla inspiradora para coaches y mentores

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install personal-brand-coach
```

## Paleta de Colores

- Primary: `#7C3AED`
- Secondary: `#8B5CF6`
- Accent: `#F59E0B`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
