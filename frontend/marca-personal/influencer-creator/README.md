# Influencer & Creator - Plantilla para KardoCore

Plantilla moderna para influencers y creadores de contenido

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install influencer-creator
```

## Paleta de Colores

- Primary: `#EC4899`
- Secondary: `#F472B6`
- Accent: `#8B5CF6`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
