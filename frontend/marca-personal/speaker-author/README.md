# Speaker & Author - Plantilla para KardoCore

Plantilla profesional para conferencistas y autores

## Características

- Diseño responsive con **KardoCSS**
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado
- Clases utilitarias de KardoCSS

## Instalación

```bash
kardo theme install speaker-author
```

## Paleta de Colores

- Primary: `#0F172A`
- Secondary: `#334155`
- Accent: `#3B82F6`

## Uso de KardoCSS

Esta plantilla utiliza KardoCSS para el diseño. Puedes personalizar los estilos editando `static/css/custom.css`.
