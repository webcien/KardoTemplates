# Language School - Plantilla para KardoCore

Plantilla dinámica para escuelas de idiomas y profesores de lenguas extranjeras

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install language-school
```

## Paleta de Colores

- Primary: `#EF4444`
- Secondary: `#F87171`
- Accent: `#3B82F6`
