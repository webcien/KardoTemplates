# Online Academy - Plantilla para KardoCore

Plantilla moderna para plataformas de educación online, cursos y academias virtuales

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install online-academy
```

## Paleta de Colores

- Primary: `#3B82F6`
- Secondary: `#60A5FA`
- Accent: `#F59E0B`
