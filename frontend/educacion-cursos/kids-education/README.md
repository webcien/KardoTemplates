# Kids Education - Plantilla para KardoCore

Plantilla colorida y divertida para guarderías, preescolares y educación infantil

## Características

- Diseño responsive
- SEO optimizado
- Accesibilidad WCAG 2.1
- Rendimiento optimizado

## Instalación

```bash
kardo theme install kids-education
```

## Paleta de Colores

- Primary: `#F59E0B`
- Secondary: `#FBBF24`
- Accent: `#EC4899`
