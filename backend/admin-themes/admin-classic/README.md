# Classic Admin - Plantilla Backend para KardoCore

Panel de administración clásico y tradicional, fácil de usar

## Características

- Sidebar colapsable y responsive
- Dashboard con estadísticas y gráficos
- Tablas de datos avanzadas
- Formularios optimizados
- Compatible con **KardoCSS**
- Modo oscuro incluido

## Instalación

```bash
kardo theme install admin-classic --backend
```

## Paleta de Colores

- Primary: `#1E40AF`
- Secondary: `#3B82F6`
- Accent: `#059669`

## Componentes Incluidos

- Dashboard principal
- Gestión de posts
- Gestión de páginas
- Biblioteca de medios
- Gestión de usuarios
- Configuración del sitio
