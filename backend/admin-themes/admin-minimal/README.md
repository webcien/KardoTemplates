# Minimal Admin - Plantilla Backend para KardoCore

Panel de administración ultra minimalista enfocado en contenido

## Características

- Sidebar colapsable y responsive
- Dashboard con estadísticas y gráficos
- Tablas de datos avanzadas
- Formularios optimizados
- Compatible con **KardoCSS**
- Modo oscuro incluido

## Instalación

```bash
kardo theme install admin-minimal --backend
```

## Paleta de Colores

- Primary: `#0F172A`
- Secondary: `#334155`
- Accent: `#0EA5E9`

## Componentes Incluidos

- Dashboard principal
- Gestión de posts
- Gestión de páginas
- Biblioteca de medios
- Gestión de usuarios
- Configuración del sitio
