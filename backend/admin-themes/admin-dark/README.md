# Dark Admin - Plantilla Backend para KardoCore

Panel de administración con modo oscuro elegante y profesional

## Características

- Sidebar colapsable y responsive
- Dashboard con estadísticas y gráficos
- Tablas de datos avanzadas
- Formularios optimizados
- Compatible con **KardoCSS**
- Modo oscuro incluido

## Instalación

```bash
kardo theme install admin-dark --backend
```

## Paleta de Colores

- Primary: `#8B5CF6`
- Secondary: `#A78BFA`
- Accent: `#EC4899`

## Componentes Incluidos

- Dashboard principal
- Gestión de posts
- Gestión de páginas
- Biblioteca de medios
- Gestión de usuarios
- Configuración del sitio
