# Creative Admin - Plantilla Backend para KardoCore

Panel de administración creativo con diseño innovador

## Características

- Sidebar colapsable y responsive
- Dashboard con estadísticas y gráficos
- Tablas de datos avanzadas
- Formularios optimizados
- Compatible con **KardoCSS**
- Modo oscuro incluido

## Instalación

```bash
kardo theme install admin-creative --backend
```

## Paleta de Colores

- Primary: `#EC4899`
- Secondary: `#F472B6`
- Accent: `#8B5CF6`

## Componentes Incluidos

- Dashboard principal
- Gestión de posts
- Gestión de páginas
- Biblioteca de medios
- Gestión de usuarios
- Configuración del sitio
