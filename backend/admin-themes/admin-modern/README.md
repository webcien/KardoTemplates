# Modern Admin - Plantilla Backend para KardoCore

Panel de administración moderno y minimalista con diseño limpio

## Características

- Sidebar colapsable y responsive
- Dashboard con estadísticas y gráficos
- Tablas de datos avanzadas
- Formularios optimizados
- Compatible con **KardoCSS**
- Modo oscuro incluido

## Instalación

```bash
kardo theme install admin-modern --backend
```

## Paleta de Colores

- Primary: `#3B82F6`
- Secondary: `#60A5FA`
- Accent: `#10B981`

## Componentes Incluidos

- Dashboard principal
- Gestión de posts
- Gestión de páginas
- Biblioteca de medios
- Gestión de usuarios
- Configuración del sitio
