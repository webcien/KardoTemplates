# E-commerce Dashboard - Plantilla Backend para KardoCore

Dashboard especializado para tiendas online y ventas

## Características

- Sidebar colapsable y responsive
- Dashboard con estadísticas y gráficos
- Tablas de datos avanzadas
- Formularios optimizados
- Compatible con **KardoCSS**
- Modo oscuro incluido

## Instalación

```bash
kardo theme install dashboard-ecommerce --backend
```

## Paleta de Colores

- Primary: `#10B981`
- Secondary: `#34D399`
- Accent: `#3B82F6`

## Componentes Incluidos

- Dashboard principal
- Gestión de posts
- Gestión de páginas
- Biblioteca de medios
- Gestión de usuarios
- Configuración del sitio
