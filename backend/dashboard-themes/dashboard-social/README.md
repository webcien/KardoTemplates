# Social Media Dashboard - Plantilla Backend para KardoCore

Dashboard para gestión de redes sociales y contenido

## Características

- Sidebar colapsable y responsive
- Dashboard con estadísticas y gráficos
- Tablas de datos avanzadas
- Formularios optimizados
- Compatible con **KardoCSS**
- Modo oscuro incluido

## Instalación

```bash
kardo theme install dashboard-social --backend
```

## Paleta de Colores

- Primary: `#EC4899`
- Secondary: `#F472B6`
- Accent: `#8B5CF6`

## Componentes Incluidos

- Dashboard principal
- Gestión de posts
- Gestión de páginas
- Biblioteca de medios
- Gestión de usuarios
- Configuración del sitio
