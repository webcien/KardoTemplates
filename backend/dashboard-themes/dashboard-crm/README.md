# CRM Dashboard - Plantilla Backend para KardoCore

Dashboard para gestión de relaciones con clientes

## Características

- Sidebar colapsable y responsive
- Dashboard con estadísticas y gráficos
- Tablas de datos avanzadas
- Formularios optimizados
- Compatible con **KardoCSS**
- Modo oscuro incluido

## Instalación

```bash
kardo theme install dashboard-crm --backend
```

## Paleta de Colores

- Primary: `#0EA5E9`
- Secondary: `#06B6D4`
- Accent: `#10B981`

## Componentes Incluidos

- Dashboard principal
- Gestión de posts
- Gestión de páginas
- Biblioteca de medios
- Gestión de usuarios
- Configuración del sitio
