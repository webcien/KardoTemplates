# Project Dashboard - Plantilla Backend para KardoCore

Dashboard para gestión de proyectos y tareas

## Características

- Sidebar colapsable y responsive
- Dashboard con estadísticas y gráficos
- Tablas de datos avanzadas
- Formularios optimizados
- Compatible con **KardoCSS**
- Modo oscuro incluido

## Instalación

```bash
kardo theme install dashboard-project --backend
```

## Paleta de Colores

- Primary: `#F59E0B`
- Secondary: `#FBBF24`
- Accent: `#3B82F6`

## Componentes Incluidos

- Dashboard principal
- Gestión de posts
- Gestión de páginas
- Biblioteca de medios
- Gestión de usuarios
- Configuración del sitio
