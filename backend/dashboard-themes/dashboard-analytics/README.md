# Analytics Dashboard - Plantilla Backend para KardoCore

Dashboard enfocado en análisis de datos y métricas

## Características

- Sidebar colapsable y responsive
- Dashboard con estadísticas y gráficos
- Tablas de datos avanzadas
- Formularios optimizados
- Compatible con **KardoCSS**
- Modo oscuro incluido

## Instalación

```bash
kardo theme install dashboard-analytics --backend
```

## Paleta de Colores

- Primary: `#7C3AED`
- Secondary: `#8B5CF6`
- Accent: `#F59E0B`

## Componentes Incluidos

- Dashboard principal
- Gestión de posts
- Gestión de páginas
- Biblioteca de medios
- Gestión de usuarios
- Configuración del sitio
