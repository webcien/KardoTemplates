# KardoTemplates - Plantillas Profesionales para KardoCore

![KardoCore](https://img.shields.io/badge/KardoCore-%3E%3D0.1.0-blue.svg)
![Templates](https://img.shields.io/badge/plantillas-60-brightgreen.svg)
![License](https://img.shields.io/badge/license-MIT-green.svg)

**KardoTemplates** es una colección oficial de plantillas profesionales, modernas y totalmente responsivas diseñadas para funcionar a la perfección con **KardoCore**, el framework de CMS híbrido con IA nativa.

Este repositorio contiene más de 60 plantillas listas para usar, organizadas por categorías de negocio y casos de uso, para acelerar el desarrollo de cualquier proyecto web.

## ✨ Características Principales

- **Integración Perfecta**: Diseñadas específicamente para el motor de temas **KardoTheme** de KardoCore.
- **KardoCSS Inside**: Construidas sobre **KardoCSS**, nuestro framework CSS utilitario inspirado en TailwindCSS, para un diseño rápido, consistente y personalizable.
- **Totalmente Responsivas**: Adaptadas para funcionar en cualquier dispositivo, desde móviles hasta ordenadores de escritorio.
- **Categorías Claras**: Organizadas en 15 categorías de frontend y 2 de backend para encontrar fácilmente la plantilla que necesitas.
- **SEO Optimizado**: Estructura semántica y metadatos listos para un buen posicionamiento en buscadores.
- **Fácil de Instalar**: Se pueden instalar con un solo comando a través del CLI de KardoCore.
- **Código Abierto**: Licencia MIT para que puedas usarlas y modificarlas libremente.

## 🚀 Inicio Rápido

Instalar una plantilla es tan simple como ejecutar un comando en tu proyecto KardoCore:

```bash
# Instalar una plantilla frontend (ej. wellness-clinic)
kardo theme install wellness-clinic

# Instalar una plantilla backend (ej. admin-modern)
kardo theme install admin-modern --backend
```

Para instrucciones más detalladas, consulta nuestra [**Guía de Instalación**](./docs/INSTALL.md).
